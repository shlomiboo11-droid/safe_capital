### הפרמטרים שקובעים את התחושה

```js
RAIL_TRAVEL  = -50   // vw — כמה הרכבת נעה
RAIL_EASE    = 0.6   // התנועה מסתיימת ב-60% מהמסלול, ואז מנוחה
ORB_ROTATION = 200   // deg
ORB_EASE     = 0.9   // מכנה שונה → הדיסקים לא מסונכרנים עם הרכבת
```

שני המכנים השונים (0.6 מול 0.9) הם מה שגורם לתנועה להרגיש אורגנית ולא מכנית.
ה-`transition: transform .3s ease-out` על `.orb` מוסיף אינרציה — הדיסק מגיע קצת אחרי הגלילה.

## הלוגו בהאדר — למה זה בנוי ככה

```
מנוחה   [ ▐S▌ A F E ]            --logo-w
גלילה   [ ▐S▌ ]                  --logo-w-mark  = --logo-w × 0.2141
```

ה-`<svg>` **לא משנה מידה לעולם**. מה שמשתנה זה רק ה-`<span>` שעוטף אותו
(`overflow:hidden`), ובמקביל קבוצת ה-`AFE` מתכווצת ל-`scale(.08)` לנקודה
שנמצאת בתוך המגן. ה-`AFE` מצויר לפני המגן ב-DOM, ולכן המגן בולע אותו.

זו הסיבה ש-`.brand__logo .logo` נושא `max-width:none` — ה-reset הגלובלי
`svg{max-width:100%}` היה מכווץ את ה-SVG יחד עם המסגרת, והמגן היה מקטין את
עצמו במקום שה-`AFE` ייחתך.

## מה תוקן מול המקור (במכוון)

1. **`overflow-x: clip` במקום `hidden`** — `hidden` יוצר scroll container ושובר `position:sticky`.
2. **שכבת קריאות על כרטיסים** (`.card__scrim`) — במקור הטקסט הלבן יושב ישירות על המדיה.
3. **`prefers-reduced-motion`** — כל התנועה מונעת־הגלילה נכבית, הפריסה נשמרת.
4. **`:focus-visible`** על כל אלמנט אינטראקטיבי + קישור דילוג לתוכן.
5. **`clamp()` על הטיפוגרפיה** — בטווח 1000–1900px זהה למקור לחלוטין, רק לא קורס בקצוות.
6. **rAF + cache** — מאזין גלילה אחד, המידות מחושבות מחדש רק ב-resize.
7. **תפריט נגיש** — `aria-expanded`, סגירה ב-Escape, ניהול פוקוס, נעילת גלילה.
8. **חיווי הגלילה דוהה** אחרי ה-Hero (במקור הוא נשאר לנצח).

## רצף הפתיחה

```
0ms      האתר עולה (header, רקע)
+260ms   המגן נוחת במקום הכותרת
+280ms   ה-AFE נפרש החוצה מאחוריו — בדיוק תנועת ההאדר, הפוכה
+1150ms  הלוגו דוהה ומתכווץ כלפי מעלה
+380ms   הכותרת מוקלדת מתחתיו, 22–46ms לתו, רווחים ×1.6
```

הפרמטרים ב-`INTRO` בראש `motion.js`.
גובה הכותרת ננעל לפני ההקלדה (`--title-h`) כדי שהפריסה לא תקפוץ שורה-שורה,
והנעילה משתחררת בסיום. המדידה מחכה ל-`document.fonts.ready`.
הטקסט המלא יושב ב-HTML מלכתחילה — בלי JS העמוד עדיין קריא.

## כותרת ה-Hero הנעוצה — מובייל בלבד (≤767)

```
hero = 175vh          ← מסלול גלילה
  ├─ 0 → 75vh         הכותרת נעוצה במסך, לא זזה
  │    └─ 46vh → 75vh   דעיכה רציפה (updateHeroPin)
  └─ 75vh → 175vh     ה-hero הריק נגלל החוצה, סקשן החשיפה עולה
```

הדעיכה נגמרת בדיוק ב-`hero.offsetHeight − 100vh` — הרגע שבו ראש הסקשן
הבא נוגע בתחתית המסך. לכן הכותרת **נעלמת** ולא נגללת החוצה.

`HERO_PIN_MAX` ב-`motion.js` חייב להתאים ל-media query שב-CSS (767px).
כשהנעיצה פעילה, עוגני המשפט הנעוץ עוברים לחישוב יחסי (`PINNED_REL`) —
המספרים המוחלטים נמדדו כשה-hero היה בגובה מסך אחד ולא תקפים יותר.

## תפריט מובייל

גיליון שעולה מלמטה ל-34vh (מינימום 238px), פינות מעוגלות למעלה, ידית אחיזה,
ורקע מעומעם שסוגר בלחיצה. נסגר גם ב-Escape.
ההמבורגר שלושה קווים; בפתיחה הקו האמצעי נעלם והחיצוניים מצטלבים ל-X.

## הבדל מימוש אחד ששווה להכיר

במקור, ההצמדה האנכית של הסקשן הכהה נעשית ב-JavaScript של Elementor —
הוא מחליף את האלמנט ל-`position: fixed; top: 190px` כשהוא נכנס לטווח.

כאן זה `position: sticky` נטו על `.process__stage`, עם מרכוז אנכי.
אותה תוצאה ויזואלית, בלי JS, בלי מספר קסם, ובלי layout thrashing.
