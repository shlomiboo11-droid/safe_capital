# כלי פיתוח — לא נשלחים לאוויר

## panel.js — פאנל כוונון תנועה

סליידרים חיים לאורך מסלול ההירו, לגבעה, לבית, לעוגני המשפט הנעוץ
ולפייד של סקשן התהליך. כפתור "העתק ערכים" מוציא אותם בפורמט מוכן להדבקה.

הוא מדבר עם `motion.js` דרך `window.SC_MOTION` — הממשק הזה עדיין קיים
ב-`motion.js` (סעיף בסוף הקובץ), אז הפאנל יעבוד ברגע שיוחזר.

### להחזיר לפעולה

להעתיק חזרה ל-`site/assets/` ולהוסיף לפני `</body>`:

```html
<script src="assets/panel.js"></script>
```

ואז לפתוח `http://localhost:5173/?panel=1`.
בלי הפרמטר בכתובת הסקריפט יוצא מיד ולא עושה כלום.

**להוציא שוב לפני עלייה לאוויר.**
