`build.py` + `lib.py` → `layers.json`. הרצה מחדש רק אם משנים שכונות/סובלנות.

## מקורות (שניהם נחלת הכלל / חופשי)

| שכבה | מקור | רישיון |

| 48 מדינות, 67 מחוזות אלבמה | us-atlas (Census TIGER) | נחלת הכלל |
| גבולות בירמינגהם / Mountain Brook / Vestavia Hills | OpenStreetMap דרך Nominatim | ODbL — **מחייב קרדיט** |

ODbL: צריך "© OpenStreetMap contributors" איפשהו בעמוד או בקרדיטים.

## ההיטל

Albers חרוטי שווה־שטח · lon0=-96 · lat0=37.5 · מקבילות 29.5/45.5 · K=100000.
**אותו היטל לשלוש הרמות** — ולכן הזום הוא רק שינוי viewBox, בלי חישוב מחדש.

⚠️ ההיטל הגולמי הוא y-כלפי-מעלה. ב-`lib.py` הוא הפוך (`r*cos - r0`) כי SVG
הוא y-כלפי-מטה. בלי ההיפוך המפה יוצאת משוקפת אנכית — אלבמה נוחתת בצפון.

## הערות

- `vector-effect:non-scaling-stroke` חובה — אחרת הקווים מתעבים פי 287 בזום.
- Vestavia Hills היא עירייה מפוצלת: 4 חלקים משמעותיים. חלקים מתחת ל-1%
  מהשטח הושמטו (נשמרו 98.5%). בירמינגהם: 19 חלקים → 2 (97.9%).
- אלסקה והוואי לא נכללות. אם צריך אותן — צריך היטל מורכב (albersUsa).

# בניית ה-Artifact

`site/safe-capital.artifact.html` הוא קובץ בנוי, לא מקור. **אל תערוך אותו ידנית** —
הוא נדרס בכל בנייה מחדש. המקור הוא תמיד `site/index.html` + `assets/`.

לבנות מחדש אחרי שינוי באתר: ראה את סקריפט הבנייה בהיסטוריית הגיט
(commit "publish the site as a shareable artifact"). הוא עושה שלושה דברים:

1. שולף רק את גוף ה-`<body>` — ה-Artifact בונה בעצמו doctype/html/head
2. מטמיע את ה-CSS וה-JS inline, ואת ה-webp כ-data URI
   (ה-CSP של Artifact חוסם כל מארח חיצוני, פרט ל-Google Fonts)
3. מוסיף `direction:rtl` ב-CSS ומשלים `dir`/`lang` ב-JS,
   כי תגית ה-html לא בשליטתנו שם

לפרסום עדכון: לפרסם את **אותו נתיב קובץ** ואז הלינק נשאר זהה.
